# Blood Bank Management System

A software application designed to simplify blood bank operations by organizing blood donor information, blood availability, and blood bank records in one centralized system.

## 📌 Project Overview

The **Blood Bank Management System** is a software development project focused on improving the organization and management of blood bank information. It aims to make blood-related records easier to maintain, search, and manage while reducing reliance on manual record-keeping.

## ✨ Key Features

The system can be documented around the following features, depending on what is implemented in the application:

- **Donor Management** — Maintain and manage blood donor information.
- **Blood Inventory Management** — Organize blood stock and availability records.
- **Blood Group Tracking** — Categorize blood records by blood group.
- **Record Management** — Add, view, update, and manage relevant records.
- **Search and Retrieval** — Find stored information efficiently.

## 🚀 Getting Started

### Prerequisites

Before running the project, ensure you have:

- [Visual Studio](https://visualstudio.microsoft.com/) installed.
- The .NET SDK or runtime required by the project.
- The database server or database file required by the application, if applicable.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mashrurahmed01/Blood-Bank-Management-System.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Blood-Bank-Management-System
   ```

3. Open `BloodBank.slnx` in Visual Studio.

4. Restore the required NuGet packages, if prompted.

5. Configure the database connection or other application settings if required.

6. Build and run the application from Visual Studio.
